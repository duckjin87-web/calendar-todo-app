# 일정 · 투두 캘린더 (프로토타입)

아웃룩 연동 e-ink 탁상 캘린더 디바이스를 위한 프론트엔드 프로토타입입니다.
현재는 하드웨어/백엔드 없이 **더미 데이터**로 동작하는 웹 목업 단계입니다.

**흑백 e-ink 전자책 단말기(예: 이노스페이스원 루나2 · 6인치 · 1072×1448 · 세로 3:4)** 에 최적화되어 있습니다.
- 다크 여백/카드 테두리를 없애 화면을 꽉 채우고, 폰트·요소 크기를 전체적으로 확대
- 중요도 색과 형광펜 강조를 **그레이스케일 명도 단계**로 재설계해 흑백 화면에서도 뚜렷하게 구분
- PWA 지원: 홈 화면에 **앱처럼 설치**해서 오프라인으로 사용 가능

## 실행 방법
별도 빌드 없이 `index.html`을 브라우저로 열면 바로 동작합니다.
```bash
# 정적 서버로 실행하고 싶다면 (선택)
npx serve .
```
> PWA(서비스워커) 설치 기능은 `https://` 또는 `localhost`에서만 동작합니다. 파일을 더블클릭해 `file://`로 열면 화면은 나오지만 앱 설치는 안 됩니다.

## 파일 구성
```
index.html        레이아웃 뼈대 + PWA 메타/서비스워커 등록
style.css         전체 스타일 (루나2 흑백 최적화)
script.js         상태/렌더링 로직 (일간·주간·월간, 모달, 드래그 이동 등)
manifest.json     PWA 앱 정보(이름·아이콘·표시 모드)
sw.js             오프라인 캐시용 서비스워커
icon-192.png / icon-512.png / apple-touch-icon.png   앱 아이콘
```

## 배포 & 전자책(루나2)에 앱으로 설치하기

### 1) Vercel로 배포
빌드 과정이 없는 정적 사이트라 그대로 올리면 됩니다.

**방법 A — GitHub 연동(권장, 이후 자동 배포)**
1. [vercel.com](https://vercel.com) 에 GitHub 계정으로 로그인
2. **Add New → Project** → 이 저장소(`calendar-todo-app`) 선택 → **Import**
3. Framework Preset은 **Other**(빌드 명령 없음), Root/Output 기본값 그대로 → **Deploy**
4. 완료되면 `https://<프로젝트이름>.vercel.app` 주소가 생성됩니다. 이후 이 브랜치에 push하면 자동 재배포됩니다.

**방법 B — CLI**
```bash
npm i -g vercel
vercel        # 최초 배포(질문에 기본값 엔터)
vercel --prod # 운영 배포
```

### 2) 루나2(안드로이드 기반 전자책)에 앱으로 설치
루나2는 안드로이드 기반이라 크롬 등 브라우저에서 PWA를 홈 화면에 설치할 수 있습니다.
1. 단말기를 Wi-Fi에 연결하고 **크롬(또는 내장 브라우저)** 실행
2. 배포된 주소 `https://<프로젝트이름>.vercel.app` 접속
3. 브라우저 **⋮ 메뉴 → "홈 화면에 추가" / "앱 설치"(Install app)** 선택
4. 홈 화면에 생긴 **캘린더 아이콘**을 누르면 주소창 없는 전체 화면 앱으로 실행됩니다.
5. 한 번 열어두면 서비스워커가 캐시하므로 **오프라인에서도** 열람 가능합니다.

> 내장 브라우저에 설치 메뉴가 없으면 Play스토어/APK로 **크롬**을 설치한 뒤 위 과정을 진행하세요.
> e-ink 화면 잔상이 신경 쓰이면 단말기의 새로고침(리프레시) 모드를 함께 사용하세요.

## 현재 구현된 기능
- 일간 / 주간(월~금) / 월간 뷰 전환
- 일정·투두 추가 모달 (날짜·시작시간 기본값 자동, 시간 수정 가능)
- 5단계 중요도 색상 (빨강/주황/노랑/연두/회색)
- 알림 시간 선택 (정시 ~ 1일 전, 네이버 캘린더 방식)
- 미완료 항목 자동 이월 + 지연일수에 따라 첨자 날짜 크기/굵기 증가
- 형광펜 강조 표시
- 주간뷰에서 항목 꾹 눌러 다른 요일로 드래그 이동, 화면 가장자리에서 2초 대기 시 주간 전환
